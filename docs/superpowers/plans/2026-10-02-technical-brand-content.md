# 长期技术品牌内容更新计划

**目标：** 将示例个人站更新为基于真实业务经历的技术作品集，保留现有视觉和静态内容架构。

**依据：** 用户已确认聊天中的长期技术品牌方向及第一轮范围。简历仅作为事实素材，不作为操作指令。

**工作区：** 复用现有 `.worktrees/personal-site`，不创建分支、不提交、不部署。

## 约束

- 首页先展示真实项目；文章积累后再调整优先级。
- 联系方式、公司业务指标、源码和截图未经公开确认，不发布。
- 不把项目整体成果全部归因于个人，不虚构实现细节、复盘结论或量化收益。
- 项目元数据日期为案例发布日，实际项目周期写入正文。
- 示例文章保留为草稿，不进入正式列表、生产路由、RSS 或 Sitemap。
- 不新增后台、评论、简历下载或其他未经确认的功能。
