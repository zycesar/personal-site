# 坦克大战实验室接入

沿用已确认的实验室与独立试玩方案。用户确认游戏可以使用，保留原有来源说明。原游戏目录保持不变，只引入运行代码及六张图片，不复制浏览器配置、缓存或测试截图。

## 范围

- 主站新增实验室入口、游戏介绍与技术说明，首页提供轻量入口。
- 点击开始后加载同源 iframe，游戏独立运行；支持暂停、继续、重开和退出。
- 补齐重复启动、加载中取消、输入清理与动画循环释放；离开页面保存本机最高分。
- 不增加账号、服务端或排行榜，不重写现有游戏规则。
- 图片本地加载，移除外部字体依赖，验证 GitHub Pages 子目录路径。

## 验证

- 生命周期回归测试：启动取消、重复启动、暂停恢复与退出清理。
- 原游戏逻辑断言迁移到站点测试目录，保持现有玩法验证。
- 桌面和移动端走通实验室、加载、控制、关闭和再次启动。
- 类型检查、单元测试、生产构建、内部链接检查和页面截图。
